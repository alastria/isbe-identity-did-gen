01 · Identity

Generate an identity

Create a new secp256k1 identity and protect it in an encrypted Web3 keystore. Nothing is uploaded or transmitted.

Encrypted keystore

Back up your keystore and your password separately. Neither can be recovered if lost.

02 · Registry

Generate your DID

Derive the DID, public key and proof that the ISBE registry needs, using your existing encrypted identity.

Identity details

03 · Transactions

Sign a transaction

Sign an unsigned transaction prepared by the ISBE API, or one opened from a signing link such as the evidence gateway. Signing happens here; broadcasting is a separate step.

Transaction details

Review transaction

Contract calldata is not decoded. Check the destination and network independently before signing.

04 · Key management

Import a private key

Move an existing secp256k1 key into a new password-protected keystore without typing it into a terminal command.

Import key securely

Importing does not erase unencrypted copies elsewhere. Remove them securely and back up your keystore.

05 · Key management

Export a private key

Decrypt a keystore to obtain the raw key, only when another application cannot import encrypted keystores.

High-risk operation

Anyone who receives this private key controls your identity. Where possible, import your encrypted keystore into compatible software instead.

Private keys never leave this application unless you export them.
