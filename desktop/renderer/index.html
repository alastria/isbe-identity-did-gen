01 / IDENTITY

Generate an identity

Create a new secp256k1 identity and protect it in an encrypted Web3 keystore. Nothing is uploaded or transmitted.

Encrypted keystore

Back up both your keystore and password separately. Neither can be recovered if lost.

02 / REGISTRY

Generate your DID

Derive the DID, public key and proof that the ISBE registry needs, using your existing encrypted identity.

Identity details
03 / TRANSACTIONS

Sign a transaction

Sign an unsigned transaction prepared by the ISBE API, or opened from a signing link (for example, from the evidence gateway). Signing is local; broadcasting remains a separate step.

Transaction details
REVIEW TRANSACTION

Contract calldata is not decoded. Verify the destination and network independently before signing.

04 / KEY MANAGEMENT

Import a private key

Move an existing secp256k1 key into a new password-protected keystore without placing it in a terminal command.

Import key securely

Importing does not erase unencrypted copies elsewhere. Remove them securely and back up your keystore.

05 / KEY MANAGEMENT

Export a private key

Decrypt a keystore to obtain the raw key, only when another application cannot import encrypted keystores.

High-risk operation

Anyone who receives this private key can control your identity. Prefer importing your encrypted keystore directly into compatible software.
